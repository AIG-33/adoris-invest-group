# Как обновить сессию для отображения админ панели

Если кнопка ADMIN не появляется после установки роли admin, выполните следующие шаги:

## Вариант 1: Полный перелогин
1. Выйдите из аккаунта (Logout)
2. Очистите cookies браузера для этого сайта
3. Войдите снова

## Вариант 2: Принудительное обновление сессии
1. Откройте консоль браузера (F12)
2. Выполните:
```javascript
// Очистить сессию NextAuth
localStorage.removeItem('nextauth.message')
sessionStorage.clear()
// Перезагрузить страницу
window.location.reload()
```

## Вариант 3: Проверка через API
Откройте в браузере: `/api/auth/session`
Должно показать:
```json
{
  "user": {
    "role": "admin",
    ...
  }
}
```

Если роль не "admin", значит проблема в передаче роли в сессию.
