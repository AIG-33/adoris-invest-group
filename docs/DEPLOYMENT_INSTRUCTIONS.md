# Инструкция по перезапуску приложения

## Приложение развернуто на Vercel

### Автоматический перезапуск

После push в `main` ветку, Vercel автоматически:
1. Обнаруживает изменения
2. Запускает сборку (`npm run build`)
3. Деплоит новую версию

**Проверьте статус деплоя:**
- Откройте Vercel Dashboard: https://vercel.com/dashboard
- Найдите ваш проект
- Проверьте последний деплой (должен быть "Building" или "Ready")

### Ручной перезапуск через Vercel Dashboard

1. Откройте https://vercel.com/dashboard
2. Выберите ваш проект
3. Перейдите на вкладку "Deployments"
4. Найдите последний деплой
5. Нажмите "..." (три точки) → "Redeploy"

### Ручной перезапуск через Vercel CLI

Если установлен Vercel CLI:

```bash
# Установить Vercel CLI (если не установлен)
npm i -g vercel

# Логин (если не залогинен)
vercel login

# Передеплой последней версии
vercel --prod
```

### После миграции базы данных

После выполнения SQL миграции в Supabase:

1. **Обновите Prisma Client** (выполняется автоматически при деплое через `postinstall`):
   ```bash
   npx prisma generate
   ```

2. **Перезапустите приложение** (Vercel сделает это автоматически при следующем деплое)

### Локальный перезапуск (для разработки)

```bash
# Остановить текущий процесс (Ctrl+C)

# Обновить Prisma Client
npx prisma generate

# Запустить dev сервер
npm run dev
```

### Проверка после деплоя

1. Откройте ваш сайт (например, shop.adorisgroup.com)
2. Проверьте, что:
   - Страницы загружаются корректно
   - Bulk order работает с правильными ценами
   - Настройка showPrices доступна в админке
   - Продукты отображают цены или "Price on Request"

## Важно!

⚠️ **Не забудьте выполнить SQL миграцию в Supabase** перед перезапуском:
- Используйте `prisma/migrations/add_show_prices_to_company_simple.sql`
- Или выполните команды пошагово (см. MIGRATION_SHOW_PRICES.md)
