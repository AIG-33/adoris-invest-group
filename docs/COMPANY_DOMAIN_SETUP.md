# Настройка домена компании (мультисайт)

Сайт определяет компанию по **домену из заголовка запроса** (Host). В базе у каждой компании хранится поле **domain**. Оно должно **точно совпадать** с тем, как пользователи заходят на сайт, либо с «базовым» доменом при использовании поддомена.

## Как это работает

- Запрос приходит с хоста, например: `shop.samplify.org`.
- Ищется компания с `domain = 'shop.samplify.org'` (точное совпадение).
- Если не найдена и в хосте есть поддомен (например `shop.samplify.org`), ищется компания с `domain = 'samplify.org'` (базовый домен без первой части).

Поэтому для сайта **shop.samplify.org** в базе у компании Samplify должно быть одно из:

- **Рекомендуется:** `domain = shop.samplify.org` — тогда сайт сразу будет отображать реквизиты и настройки Samplify.
- Либо: `domain = samplify.org` — тогда поддомен `shop.samplify.org` тоже будет привязан к этой компании.

Если у Samplify в базе указан, например, `samplify.com`, то для `shop.samplify.org` компания не найдётся и на сайте могут отображаться нейтральные/дефолтные подписи вместо реквизитов Samplify.

## Что сделать для Samplify и shop.samplify.org

1. **Через админку**  
   Зайти в раздел компаний, открыть Samplify и в поле **Domain** указать: `shop.samplify.org` (или `samplify.org`, если хотите привязать по базовому домену). Сохранить.

2. **Через скрипт (если компания уже есть в БД)**  
   Из корня проекта выполнить:
   ```bash
   npx ts-node --compiler-options '{"module":"CommonJS"}' scripts/update-samplify-domain.ts
   ```
   Скрипт найдёт компанию Samplify (по slug/текущему domain) и установит ей `domain = shop.samplify.org`.

После этого при заходе на **shop.samplify.org** будут подставляться реквизиты и настройки компании Samplify.

## Другие сайты

Для любого другого домена (например `shop.ivdgroup.eu`, `adorisgroup.com`) правило то же: в таблице Company у нужной компании в поле **domain** должно быть значение, совпадающее с хостом сайта или с базовым доменом (без поддомена), как описано выше.
