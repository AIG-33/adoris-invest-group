# Перезапуск деплоя после обновления DATABASE_URL

## ✅ DATABASE_URL настроен правильно!

Вы правильно обновили `DATABASE_URL`:
- ✅ Порт: **6543** (Connection Pooler)
- ✅ Параметры: `?pgbouncer=true&connection_limit=1`
- ✅ Обновлено для всех окружений

## ⚠️ ВАЖНО: Нужно перезапустить деплой!

После обновления переменных окружения в Vercel, **обязательно перезапустите деплой**, чтобы изменения вступили в силу.

### Как перезапустить деплой:

**Вариант 1: Redeploy последнего деплоя (рекомендуется)**
1. Vercel Dashboard → Ваш проект
2. Перейдите на вкладку **"Deployments"**
3. Найдите последний деплой (самый верхний)
4. Нажмите на **"..."** (три точки) справа от деплоя
5. Выберите **"Redeploy"**
6. Подтвердите перезапуск

**Вариант 2: Сделать новый коммит**
1. Сделайте небольшое изменение в коде (например, добавьте комментарий)
2. Закоммитьте и запушьте:
   ```bash
   git add .
   git commit -m "Trigger redeploy after DATABASE_URL update"
   git push origin main
   ```
3. Vercel автоматически создаст новый деплой

### После перезапуска:

1. **Подождите 2-3 минуты** пока деплой завершится
2. **Проверьте логи:**
   - Vercel Dashboard → Deployments → выберите новый деплой → "View Function Logs"
   - Ошибки `P2024` или `connection pool timeout` должны исчезнуть
3. **Проверьте сайт:**
   - Откройте сайт на новом устройстве
   - Страница должна загружаться быстро
   - Не должно быть ошибок "Application error"

### Если ошибки продолжаются:

1. Убедитесь, что деплой действительно перезапущен (проверьте время последнего деплоя)
2. Проверьте логи нового деплоя
3. Убедитесь, что `DATABASE_URL` виден в логах (можете добавить временный console.log для проверки)
4. Если проблема сохраняется, возможно нужно подождать еще несколько минут для распространения изменений

## Ожидаемый результат:

После перезапуска деплоя:
- ✅ Ошибки `Timed out fetching a new connection from the connection pool` исчезнут
- ✅ Сайт будет загружаться быстрее
- ✅ Главная страница будет открываться мгновенно
- ✅ Не будет ошибок при открытии страниц продуктов
